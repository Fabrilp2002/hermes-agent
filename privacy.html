Privacy Policy

Last updated: 2026-10-04

Hermes Agent is a personal assistant used only by its owner, Fabrizio López (fabriziolp50@gmail.com). No other users are served.

Data accessed

With the owner's consent, the app accesses the owner's Gmail, Google Drive, Docs, Sheets, Calendar and Contacts through Google APIs.

How data is used

Data is used only to produce summaries and notes for the owner. It is not sold, shared with third parties or used for advertising. Google user data is handled in accordance with the Google API Services User Data Policy, including the Limited Use requirements.

Storage

OAuth tokens and generated notes are stored on a private server controlled by the owner. Access can be revoked at any time at https://myaccount.google.com/permissions.
